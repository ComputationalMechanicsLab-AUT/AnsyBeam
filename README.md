# AnsyBeam v1.0.0

AnsyBeam is a MATLAB-based educational tool for planar Euler--Bernoulli beam analysis. It provides a simple workflow for defining beam geometry, supports, material and section properties, loads, visualising results, and exporting PDF reports.

## Key Features
- Node, element, support, nodal load, and distributed load input tables
- Linear elastic static beam analysis
- Support for point loads, nodal moments, and uniformly distributed loads
- Shear force diagram, bending moment diagram, and deflection output
- Model verification before analysis
- PDF report export

## Example Included
Simply supported beam subjected to a uniformly distributed load over the left half of the span.

## Notes
- Downward loads should be entered as negative values.
- UDLs must be applied over complete beam elements.
- This release is intended for educational use.
